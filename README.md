# Tarihsel Kelimeler Sözlüğü

## Proje Açıklaması
Bu proje, tarih araştırmacılarının ve öğrencilerin karşılaştıkları spesifik tarihsel kavramları (örn: İaşe, Seferberlik, Tımar) not alıp listeleyebilecekleri pratik bir web sözlüğü uygulamasıdır. 

## Kullanılan Teknolojiler
* **Kütüphane:** React (Vite ile oluşturuldu)
* **Veri Yönetimi:** LocalStorage API (Verilerin sayfayı yenileyince silinmemesi için)
* **Diller:** JavaScript, HTML, CSS

## Yapay Zeka (AI) Kullanım Detayları
Bu projenin geliştirilme sürecinde yönergelere uygun olarak Gemini yapay zeka asistanından şu aşamalarda destek alınmıştır:
* React Hooks (useState, useEffect) kullanılarak LocalStorage entegrasyonunun yazılması.
* Geliştirme ortamı (VS Code & Node.js) kurulumu ve terminal hata ayıklama süreçleri.

## Kurulum Adımları
Projeyi lokalinizde çalıştırmak için sırasıyla şu komutları terminale giriniz:
1. `npm install` (Gerekli paketleri kurar)
2. `npm run dev` (Geliştirici sunucusunu başlatır)ka
